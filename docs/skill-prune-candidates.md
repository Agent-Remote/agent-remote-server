# Skill state prune 候选与精确内部执行

本层为公开 prune 提供账户/单项范围、固定截止、完整损失与依赖组，以及普通模式仅整理
以启动等待的动作。公开摘要确认、分页展示和原键/operation ID 持久化回执由
`skill-prune-api.md` 所述独立服务接入。本内部计划不能直接序列化到 CLI 的 4 MiB
请求日志，也不能被当作幂等公开入口；CLI 接入仍是后续工作。

## 范围与固定时间

复用 SkillStateSelector 的用户/账户授权和稳定来源解析。规范计划保存稳定 source UUID，
名称变化不会重新解释原选择。账户必须已有 managed_v1 目录。目录范围以该账户全部保留
状态历史为初始候选；已退役身份只保留审计诊断，不是新的恢复损失或内容授权。
单项范围包含该稳定来源全部版本/安装纪元的 item checkpoint，及
source/target 分支属于该来源的迁移历史。snapshot/finalization/publication 和完整目录
作为必要的连带消费者展示，不因名称或共享摘要自动追加不相关历史。原始包和本地初始
版本永远不是初始候选，但其依赖会明确阻断状态回收。

分析固定使用非未来、有时区的 cutoff。初始候选创建时间不得晚于 cutoff；只读保护、
普通/归档截止和有效上传也在同一时刻判断。新的消费者即使晚于 cutoff 也必须进入完整
依赖闭包，因此其出现使原计划变化，而不是被时间过滤遗漏。执行以原 cutoff 重建并
比较整个计划，绝不把确认期间新到期、新创建或新解除保护的内容静默追加到原执行。

## 整理与完整依赖选择

先从范围内历史中选出在原保护下可整理的 item checkpoint，生成一个完整整理计划。
没有这类身份时无需伪造空整理计划；历史退役可独立进行。整理只改变当前等价视图，
原输入和原历史仍完整保留。整理后的保护与预计释放时间沿用既有只读投影。

对全部初始历史候选构建一次完整反向消费者闭包，保留每项直接阻断和所有输入依赖。
若消费者有保护、等待、未知时钟、活动上传、范围或原始版本阻断，该阻断沿消费者到
其输入传播。环整体处理；被阻断节点不是可执行选择。只从未被传播阻断的初始根再次
生成完整退役计划，这份计划必须无阻断。以实际选中节点间的无向连通分量展示完整依赖
组；共同依赖一个未选中的输入不把两个可独立退役的消费者错误合成一组。

完整阻断图、可执行组、选中历史及目录整理动作均为预览的一部分。执行不再择取子集。
普通模式下新释放的旧等价 head/backing 可能阻断整组历史；整理动作仍可独立执行并
启动真实等待。其他已经到期且依赖完整的组可以在同一份预览中明确选中；这不是执行时
跳过错误。预计空间只来自预先选中的完整退役历史，内容外键及新树边沿用共享 GC 规则。

## 原子执行

同一用户锁和 retention_mutation 外层保存点中，先重建原 cutoff 下的规范范围、完整图、
整理计划、分组和内容预测，再要求整份相等。随后执行已确认整理、完整选中历史退役和
精确树/额度/删除任务结算。没有可退役历史时仍允许已确认的整理动作；没有任何动作时
返回空结果。任何异常或真实内容动作与预测不一致都撤销整份业务变化。独立 worker
只处理最终提交的任务。本层增加 0044 续扫归属，不发布公开 prune 路由。

范围、依赖和安全预算沿用完整用户索引；不得逐个候选反复展开整图造成二次方扫描。
初始根/完整边/选中组均稳定排序。树的共享内容、其他账户引用和上传仍可导致合法的
零释放；不能为增加回收量扩张原候选范围。

## 持久化内容续扫归属（0044）

旧历史摘要不能区分已删除树与重新上传的同摘要树，创建时间也不是可靠的生命周期身份。
续扫必须使用 `skill_prune_content_claims`，不能从墓碑摘要或墙钟推断授权。

每行另有唯一随机 UUID，重验绑定该原生命周期身份，重复登记不能刷新。
表主键为 (user_id, account_id, source_key, kind, digest)：source_key 为 `*`（原目录范围）
或原规范 source UUID；kind 为 tree/object，category 固定 state。tree_digest 和 object_digest
按 kind 恰有一个非空并与 digest 相等。同所有者/账户外键指向账户目录；同用户/分类的
树与对象外键分别指向实际完整树/对象行。两个内容外键明确 ON DELETE CASCADE，仅丢弃
这份派生清理资格，不级联删除历史、原请求或业务内容。删除原树/对象便删除其资格；
同摘要重新上传不会继承。分类树/对象外键各有独立索引。

在实际历史退役的同一用户锁/保存点内，仅对本次真实解除外键的树和它原有状态对象登记
归属。预览无写入；同范围重试去重。后续账户预览可使用该账户全部归属；单项预览只用
原相同 source_key。目录请求产生的归属不会被某个单项请求隐式接管。
树归属不算硬保护或保留历史外键；它是明确分类的清理元数据。其树/对象仍需通过正常
保护、保留外键、等待和上传检查。树未到期可稍后清理；同分类零预留租约使无树对象暂留
额度时，独立对象归属继续存在，租约结束后再清理。deleting 对象仍由原 worker 处理，
候选不会重复结算或建立另一删除任务。

归属同时进入完整用户索引预算与原计划事实重验。物理删除最终移除对象时，其归属也
消失。升级只添加空表，不从旧墓碑推造授权；降级在任何归属存在时必须先拒绝，不能
丢失尚未完成的清理资格。协调备份包含本表。尚无归属的历史遗留无引用树/对象，需要
将来的显式存储清理授权，不能自动按账户归属猜测。
